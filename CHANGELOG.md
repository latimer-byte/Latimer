# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-10

### Added
- Initial project scaffolding with React + Vite + TypeScript.
- Integrated Tailwind CSS 4.0 and shadcn/ui.
- Implemented `useDeriv` custom hook for WebSocket management.
- Added real-time tick subscription and visualization.
- Integrated Gemini AI for market sentiment analysis ("Vibe Check").
- Created `MarketSelector` for switching between Deriv assets.
- Implemented `AuthPanel` for secure API token authorization.
- Added `TradeControls` for Rise/Fall trade execution.
- Created `PositionsPanel` to track active trades.
- Implemented "Mosaic" bento-grid layout for the main dashboard.
- Added responsive design for mobile and desktop.
- Included comprehensive documentation (README, VIBE_CODING).
